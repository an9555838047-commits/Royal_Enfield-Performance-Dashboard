# 🏍️ Royal Enfield Sales Dashboard

A sleek, modern, and interactive sales performance dashboard built with **HTML, CSS, and Chart.js**. This project transforms raw data into a beautiful visual experience using a glassmorphism UI, smooth background animations, and custom SVG artwork.

## ✨ Features

* 📊 **Interactive Data Visualization:** Features three distinct charts powered by Chart.js (Line Chart, Bar Chart, and Doughnut Chart) with clearly defined axes and bottom-docked legends.
* 🎨 **Glassmorphism UI:** Semi-transparent, frosted-glass data cards that "pop" and lift upon hover.
* 🌊 **Animated Gradient Background:** A continuously shifting, soft pastel pink and blue gradient that brings the page to life.
* ⚙️ **Pure SVG Animations:** Includes a custom-coded Royal Enfield bike logo with a floating chassis and rotating wheels—no external image hosting required!
* 📱 **Responsive Layout:** A flexible grid system that adapts cleanly to different screen sizes and devices.

## 🛠️ Technologies Used

* **HTML5:** Semantic structure and pure inline SVG generation.
* **CSS3:** Keyframe animations, flexbox layout, and backdrop-filters for the glass effect.
* **JavaScript:** DOM manipulation and chart rendering.
* **[Chart.js](https://www.chartjs.org/):** An open-source JavaScript library for data visualization.
* **Google Fonts:** Utilizing the 'Poppins' font family for a clean, modern aesthetic.
